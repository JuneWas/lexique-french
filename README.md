# LEXIQUE v13 — 思想のための仏語単語帳

HTML・CSS・JavaScriptの静的Webアプリです。基礎フランス語1000語 v1.1と、従来の思想・哲学100語（ラカン20語・フーコー80語）を切り替えて学習できます。React / Vue / npm / ビルドは不要です。

## 使い方

1. 上部の「教材」で基礎1000語または思想・哲学100語を選択します。
2. 単語帳では原語・日本語検索、答えの表示・非表示、発音、詳細画面でのお気に入りを使えます。基礎1000語はZone・品詞でも絞り込めます。
3. 「30日学習」で開始日を登録し、「今日の学習を開始」を押します。
4. 「意味を表示」で答えを見てから「覚えた」「覚えていない」を判定します。保存に成功したら次へ進みます。「前／次」だけでは判定済みになりません。
5. 途中で閉じても同じDay・同じ位置から再開できます。開始日からの日付上の予定と、実際に選択中の学習Dayは別です。休んでも自動スキップ・進捗リセットはありません。
6. Day選択欄や30日間の記録から、任意のDayへ移動できます。200語すべてを判定したDayは完了表示になります。未判定のまま末尾へ進んだ場合は「未判定の単語へ」で戻れます。
7. 「復習」で基礎1000語の苦手単語を学習できます。思想100語を選んでいる場合は従来の10語復習です。
8. 「設定 → 書き出す」で学習データをバックアップします。

## 30日方式

| 周回 | Day | Zone |
|---|---|---|
| 1 | 1〜5 | 1〜5 |
| 2 | 6〜10 | 1〜5 |
| 3 | 11〜15 | 1〜5 |
| 4 | 16〜20 | 1〜5 |
| 5 | 21〜25 | 1〜5 |
| 6 | 26〜30 | 1〜5 |

各Zone200語、毎周1000語を繰り返し、計6000語を確認します。「覚えた」語も次の周回で出題します。
「習得率」は選択中のDayについて、判定済みの単語のうち最新の判定が「覚えた」の割合です。未判定語は分母に含みません。これは自己判定による学習指標です。
同一Day・同一語を再判定しても過去の判定は配列に残ります。画面の集計にはそのDayの最新判定を使います。異なるDay（周回）の結果は独立しています。
苦手語はメイン学習または苦手語復習の直近判定が「覚えていない」の語です。苦手語復習は専用の履歴へ保存され、過去のDayの結果・完了状況を変えません。

## ローカル起動

ZIPを展開し、このREADMEがあるフォルダで次を実行します（Python 3が必要）。

macOS / Linux:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Windows:

```powershell
py -m http.server 8000 --bind 127.0.0.1 --directory dist
```

`http://localhost:8000` をブラウザで開きます。終了は Ctrl+C です。

### 同じWi-FiのiPhone

サーバーを停止し、`--bind 127.0.0.1` を `--bind 0.0.0.0` に変えて起動します。信頼できる同じWi-Fiに接続したiPhoneのSafariで `http://パソコンのIPv4アドレス:8000` を開きます。必要ならパソコンのファイアウォールをプライベートネットワークのみ許可してください。同じネットワーク内の他端末からもアクセス可能です。ルーターのポート開放は不要です。
パソコンの起動中・サーバー実行中だけ使えます。常時利用は既存のHTTPSサイトを使ってください。

公開先: https://lacan-lexique-junya.rightcloud11.chatgpt.site

Safariの共有メニューからホーム画面に追加できます。サービスワーカーによるオフライン対応や端末間の自動同期は実装していません。

## 音声

端末の `speechSynthesis` のフランス語音声を使用します。Google音声生成APIは呼び出しません。APIキーや音声生成課金は不要です。声・速度は設定で変更できます。フランス語音声がない場合は端末に追加し、音声一覧を更新してください。
`dist/audio/achird/` は以前生成した20語の保存用MP3で、現行アプリは使用しません。

## 保存・移行・バックアップ

- 既存の `lacan.lexique.v1`: お気に入り・旧10語復習の記録・過去の登録単語・音声設定。既存のキーとIDを維持。
- 新規の `lexique.learning.v13`: 開始日、選択Day、教材、各Dayの200語のID・位置・判定履歴、苦手語、専用復習履歴と再開位置。
- Day完了・周回集計は保存した判定履歴から算出します。
- バックアップ形式v3は両方のデータと音声設定を一つのJSONに含みます。旧v1/v2も読み込み可能で、30日学習の進捗と基礎教材のお気に入りは保持します。旧思想教材の記録はバックアップ内容で置き換わります。
- v3の読み込みは確認後、記録一式を置き換えます。不正な内容は保存前に拒否します。読み込めない既存データは自動消去せず、書き出しで原本を退避できます（原本退避ファイルは通常の復元ファイルではありません）。
- このソースZIPに個人の学習記録は含まれません。ブラウザ削除・端末変更前に書き出してください。URLやポートが変わると別の保存領域になるため、自動移行はされません。
- 複数タブで同時に学習せず、一つのタブを使ってください。保存容量不足のときは通知し、30日学習の判定を進めません。

## マスターデータ

添付 `content/french_core1000_v1_1_qa.xlsx` の「1000 Words QA」シート1000行をそのまま取り込みました。`dist/core1000.json` と `dist/core1000.js` に全列を保持し、元のID・行順・表記・訳語は変更していません。マスターのSHA-256も記録しています。

表示時の変換は `core-adapter.js` に分離しています。元IDは `sourceId` と原データの `id` に保持し、アプリ内部だけ `core:元ID` にして、`lac-...` / `fou-...` / `usr-...` と区別します。Zoneと学習順は比較用に数値化します。品詞表示は function=機能語、verb=動詞、noun=名詞、adverb=副詞、adjective=形容詞です。細分類を推測していません。genderは原データの値がある場合だけ表示します。

v1.1は編集・QA版で、外部辞書との全件照合は未完了です。未検証のfrequency_rankとcefrは元の空欄を保持し、画面で推測表示しません。

## GitHub Pagesへの公開

リポジトリの **Settings → Pages → Build and deployment → Source** を
**GitHub Actions** に設定してください。
`.github/workflows/pages.yml` は `main` へのpush時に既存テストを実行し、
成功した場合に `dist` をGitHub Pagesへ公開します。
Actions画面の「Deploy LEXIQUE to GitHub Pages」から、`main` を選んで
「Run workflow」で手動公開することもできます。

標準の公開URLは https://junewas.github.io/lexique-french/ です。
実際の公開先はActionsのdeployジョブの環境リンクで確認できます。
ホーム画面からもリポジトリ配下のURLを開けるよう、manifestのstart_urlは相対パスです。
以前のサイトの学習記録はURL変更では移行されません。バックアップがある場合は
新サイトの設定から読み込んでください。

## 200語の連続読み上げ

基礎1000語の単語帳上部でZoneを選び、「200語を読む」を押すと、選んだ200語のフランス語を学習順に読み上げます。検索・品詞の絞り込みには影響されません。速度は0.6〜1.2倍で調整でき、設定画面の音声速度と共有・保存されます。再生中の速度変更は次の単語から反映されます。

一時停止後の再開は、その単語の先頭からです。「停止」、読み上げZone変更、画面移動、個別の発音再生で連続読み上げを終了します。フランス語音声が必要です。iPhoneでは画面ロックやバックグラウンド移行で中断する場合があるため、画面を開いたまま使ってください。中断時は「再開」で再試行できます。

## 例文と日本語訳

全1100語に、学習用のフランス語例文1文と日本語訳を追加しています。
単語帳・詳細・答えを表示した学習カードで確認できます。
単語帳では「答えを隠す」で単語の訳・例文・例文訳をまとめて隠します。
例文は本アプリ向けの作例であり、著作からの引用ではありません。
思想・哲学の例文も概念の用法を学ぶための文で、定義の網羅や原典の引用を意図しません。

例文の原稿は `content/examples/*.tsv` にID・仏文・和訳の3列で保存しています。
元のXLSX・単語マスターと学習記録のIDは変更しません。
編集後は次を実行して配信ファイルと対応検査を更新します。

```sh
python3 scripts/build-examples.py
node tests/examples.cjs
node tests/integration.cjs
```

連続読み上げの「単語の間隔」で、読み終わりから次の単語までの待ち時間を0〜5秒（0.5秒刻み）に調整できます。初期値は0秒です。設定は保存され、バックアップにも含まれます。変更は次の待ち時間から反映されます。待ち時間中の一時停止後は、再開すると次の単語を読みます。停止・画面移動・Zone変更時は予約された再生も取り消します。

# LEXIQUE — 基礎フランス語・思想のための単語帳

**[アプリを開く](https://junewas.github.io/lexique-french/)**

基礎フランス語1000語と思想・哲学100語を、単語一覧・例文・音声・復習で学べる静的Webアプリです。パソコンやiPhoneのブラウザで利用できます。ログインやAPIキーは不要です。

| 教材 | 収録内容 |
| --- | --- |
| 基礎フランス語1000語 | 200語ずつの5つのZone、30日学習、苦手語復習、200語の連続読み上げ |
| 思想・哲学100語 | ラカン20語・フーコー80語、解説・関連語、10語ずつの復習 |

全1100語にフランス語の例文1文と日本語訳を収録しています。学習記録は利用中のブラウザに保存されます。

## 使い始める

1. [公開サイト](https://junewas.github.io/lexique-french/)を開き、上部の「教材」を選びます。
2. 「単語帳」で単語を探し、「答えを見る」で日本語の意味・例文・例文の和訳を確認します。
3. 単語の横の音声ボタンで発音を聞けます。フランス語の単語を押すと、詳細画面とお気に入り操作を開けます。
4. 基礎教材を毎日進める場合は「30日学習」で開始日を登録します。
5. 学習記録を残すため、ときどき「設定 → 書き出す」でバックアップしてください。

iPhoneではSafariの共有メニューから「ホーム画面に追加」もできます。サービスワーカーによるオフライン対応と端末間の自動同期は実装していません。

## 単語帳・例文

- フランス語・日本語で検索できます。基礎教材はZone・品詞、お気に入りでも絞り込めます。
- 上部の「すべての日本語の答えを見る」で、一括表示できます。もう一度押すと一括で隠せます。検索・絞り込み後も一括表示の設定を引き継ぎます。
- 各単語の答えは「日本語の意味 → フランス語例文 → 例文の和訳」の順で表示します。右下の小さな「答えを隠す」で、その単語の答え全体を隠します。
- 例文は詳細画面や、答えを表示した学習カードでも確認できます。

例文は本アプリ向けに作成した学習用の文で、著作からの引用ではありません。思想・哲学の用例は、概念の定義を網羅するものではありません。

## 200語をまとめて聞く

基礎1000語の単語帳上部で、**読み上げるZone**を選んで「200語を読む」を押します。そのZoneのフランス語200語を学習順に読み上げます。検索・品詞・お気に入りの絞り込みに関係なく、選んだZone全体が対象です。日本語訳と例文は連続読み上げの対象に含みません。

| 操作 | 動作 |
| --- | --- |
| 速度 | 0.6〜1.2倍を0.05刻みで調整。変更は次の単語から反映 |
| 単語の間隔 | 読み終わりから次の単語まで0〜5秒、0.5秒刻みで調整。初期値は0秒。変更は次の待ち時間から反映 |
| 一時停止・再開 | 発音中に止めた場合は、その単語の先頭から再開。単語間の待ち時間中に止めた場合は、次の単語から再開 |
| 停止 | 連続読み上げと、予約されている次の再生を終了 |

速度と間隔はブラウザに保存され、バックアップにも含まれます。速度は「設定」の音声速度と共通です。連続読み上げの再生位置はページの再読み込みでは引き継ぎません。

読み上げ中に元の一時停止ボタンが画面外へ出ると、**下部ナビのすぐ上・右端に小さな一時停止ボタン**が表示されます。一時停止後は「再開」に切り替わります。元のボタンが見える位置に戻るか、停止・再生完了・画面移動をすると隠れます。

読み上げZoneの変更、画面移動、個別の発音再生でも連続読み上げを終了します。

### 音声とiPhoneでの利用

端末のフランス語合成音声（`speechSynthesis`）を使います。声は「設定」で選べます。フランス語音声がない場合は端末に追加し、「音声一覧を更新」を押してください。音声の種類・品質・利用可否は端末とOSによって異なります。本アプリからGoogle音声生成APIは呼び出しません。

iPhoneでは画面ロックやバックグラウンド移行で中断する場合があります。連続読み上げ中は画面を開いたままお使いください。中断時は「再開」で再試行できます。実機Safariでの音声再生は、各端末で確認してください。

## 30日学習と復習

基礎1000語を200語ずつ5日で1周し、30日で6周します。「覚えた」単語も次の周回で再び出題します。

| 周回 | Day | 学習するZone |
| --- | --- | --- |
| 1 | 1〜5 | 1〜5 |
| 2 | 6〜10 | 1〜5 |
| 3 | 11〜15 | 1〜5 |
| 4 | 16〜20 | 1〜5 |
| 5 | 21〜25 | 1〜5 |
| 6 | 26〜30 | 1〜5 |

「今日の学習を開始」からカードを開き、「意味を表示」で答えを見て、「覚えた」「覚えていない」を選びます。保存に成功すると次の語へ進みます。「前／次」で移動するだけでは判定済みになりません。

- 200語すべてを判定すると、そのDayが完了します。未判定のまま末尾に着いた場合は「未判定の単語へ」で戻れます。
- 学習Dayと位置は保存され、途中から再開できます。日付上の予定と選択中のDayは別です。休んでも自動スキップや進捗リセットはありません。
- Day選択欄や30日間の記録から、任意のDayに移動できます。
- 習得率は、そのDayで判定済みの語のうち、最新の判定が「覚えた」である割合です。未判定語は分母に含みません。
- 再判定の履歴は残ります。異なるDayの判定は独立しています。

「復習」では、基礎教材の直近判定が「覚えていない」の語を学べます。苦手語復習は専用の履歴へ保存し、過去のDayの完了状況を変えません。思想・哲学教材では10語ずつの復習を利用できます。

## 保存・バックアップ

学習記録はサーバーではなく、ブラウザの`localStorage`に保存します。

| 保存キー | 内容 |
| --- | --- |
| `lacan.lexique.v1` | お気に入り、思想教材の復習記録、以前の登録単語、音声設定（声・速度・単語間隔） |
| `lexique.learning.v13` | 開始日、選択Day・教材、各Dayの単語ID・位置・判定履歴、苦手語とその復習履歴・位置 |

「設定 → 書き出す」で両方の記録と音声設定を含むJSON（バックアップv3）を保存し、「読み込む」で復元します。

- v3の復元は、確認後に記録一式を置き換えます。不正なデータは保存前に拒否します。
- 旧v1/v2も読み込めます。30日学習の進捗と基礎教材のお気に入りを保持し、思想教材の記録はバックアップの内容で置き換えます。
- 読み込めない保存データは自動削除しません。書き出しで原本を退避できますが、原本退避ファイルは通常の復元用ファイルではありません。
- 端末・ブラウザ・サイトのドメイン・ポートが変わると、保存領域が異なります。旧サイトからの自動移行はありません。
- ブラウザのデータ削除や端末変更の前にバックアップしてください。複数タブでの同時学習は避けてください。保存容量不足のときは通知し、30日学習の判定を進めません。

## ローカルで起動する

HTML・CSS・JavaScriptのみのアプリです。npmパッケージの導入やアプリのビルドは不要です。リポジトリを取得し、ルートディレクトリでPython 3のHTTPサーバーを起動します。

macOS / Linux:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

Windows:

```powershell
py -m http.server 8000 --bind 127.0.0.1 --directory dist
```

ブラウザで `http://127.0.0.1:8000` を開きます。終了はCtrl+Cです。

同じWi-FiのiPhoneで開く場合は、信頼できるネットワーク上で`--bind 0.0.0.0`に変更し、Safariから`http://パソコンのIPv4アドレス:8000`を開きます。必要に応じてファイアウォールのプライベートネットワーク側を許可してください。パソコンとサーバーの起動中のみ利用できます。ルーターのポート開放は不要です。

## テスト

CIと同じNode.js 22を推奨します。外部パッケージは不要です。リポジトリのルートで実行してください。

```sh
node tests/v13.cjs
node tests/integration.cjs
node tests/bulk-speech.cjs
node tests/examples.cjs
node check.cjs
```

| テスト | 主な確認内容 |
| --- | --- |
| `tests/v13.cjs` | 教材対応、1100語のID、Zone構成、30日・6000判定、履歴・保存データ検証 |
| `tests/integration.cjs` | 検索・絞り込み、お気に入り、例文表示、保存・再読み込み、バックアップ互換性 |
| `tests/bulk-speech.cjs` | 全Zoneの読み上げ順、速度・間隔、一時停止・再開・停止、待機取消、音声未検出 |
| `tests/examples.cjs` | 全1100語の例文・和訳、ID対応、原稿と配信データの一致 |
| `check.cjs` | 思想100語、関連参照、旧バックアップ・登録単語・品詞の互換性 |

`check.cjs`は`dist/words.json`を再生成します。音声テストはモックを使います。実際の発音、端末の音声一覧、Safariの表示やファイル操作を保証するものではありません。

## 教材データの更新

### 基礎1000語

原本は[`content/french_core1000_v1_1_qa.xlsx`](content/french_core1000_v1_1_qa.xlsx)の「1000 Words QA」シートです。`dist/core1000.json`と`dist/core1000.js`に元の全列・ID・行順・表記・訳語を保持し、原本のSHA-256も記録します。

```sh
python3 scripts/import-core.py content/french_core1000_v1_1_qa.xlsx
```

この操作は配信データを上書きします。更新後は上記のテスト一式を実行してください。教材の版を更新する場合はインポートスクリプトの`version`も変更します。

`dist/core-adapter.js`で表示用に変換し、アプリ内部のIDは`core:元ID`とします。元IDは`sourceId`にも残します。開始済みDayは当初の200語IDを保持するため、順序変更で学習位置がずれません。IDを削除・改名する場合は別途移行設計が必要です。不明IDの履歴は保持し、教材不一致を表示します。

品詞は原本の分類を使います。

| 原本 | 表示 |
| --- | --- |
| `function` | 機能語（代名詞・冠詞・前置詞などを含む） |
| `verb` | 動詞 |
| `noun` | 名詞 |
| `adverb` | 副詞 |
| `adjective` | 形容詞 |

性は原本に値がある場合のみ表示します。教材v1.1は編集・QA版で、外部辞書との全件照合は未完了です。未検証の頻度順位・CEFRは空欄のまま保持し、推測表示しません。

### 例文

[`content/examples/`](content/examples/)のTSVを編集します。各行はID・フランス語例文・日本語訳の3列です。基礎教材5ファイルと思想教材1ファイルに分かれています。

```sh
python3 scripts/build-examples.py
node tests/examples.cjs
node tests/integration.cjs
```

生成した`dist/examples.js`も原稿と一緒にコミットしてください。元の単語マスターと学習記録のIDは変更しません。

## GitHub Pagesへの公開

公開先は **https://junewas.github.io/lexique-french/** です。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
2. 変更をコミットして`main`へpushします。
3. [Actions](https://github.com/JuneWas/lexique-french/actions)の「Deploy LEXIQUE to GitHub Pages」を確認します。テストに成功すると`dist`が公開されます。

[公開ワークフロー](.github/workflows/pages.yml)は手動実行にも対応しています。Actionsの「Run workflow」で`main`を選んでください。公開URLはdeployジョブの環境リンクでも確認できます。ホーム画面からリポジトリ配下へ戻れるよう、manifestの`start_url`は相対パスです。

無料プランでのGitHub Pages利用には公開リポジトリが必要です。旧公開サービス用の`.openai/hosting.json`は残っていますが、現在のGitHub Pages公開では使用しません。
